# Mentor

Aplicación de productividad personal con un mentor basado en inteligencia artificial.

## Estructura

- `app/`: Backend Java, Spring Boot y PostgreSQL.
- `mentor-mobile/`: Aplicación móvil con Expo y React Native.

## Tecnologías

### Backend
- Java
- Spring Boot
- PostgreSQL
- API REST

### Mobile
- React Native
- Expo
- TypeScript

## Configuración

Configura las variables de entorno necesarias en cada componente. No subas claves API ni credenciales al repositorio.
